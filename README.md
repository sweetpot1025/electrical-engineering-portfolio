# 郭浩田 · 电气工程项目作品集

**Haotian Guo | Electrical Engineering Portfolio**

河南理工大学电气工程及其自动化本科，悉尼大学电气工程硕士在读。关注电气运维、数据中心基础设施供配电、设备运行与故障分析。

| 序号 | 项目 | 内容 |
|---|---|---|
| 01 | **[井下供配电一次系统设计](01-本科毕设-供配电系统/)** | 本科毕业设计｜负荷计算、短路分析与设备选型 |
| 02 | **[三相电力系统与短路故障分析](02-ELEC5204-短路分析/)** | 硕士课程｜MATLAB / Simulink、三相短路与接地故障 |
| 03 | **[多机系统动态稳定性分析](03-ELEC5211-稳定性分析/)** | 硕士课程｜潮流、动态响应与临界故障清除时间 |
| 04 | **[配电网运行与家庭储能](04-ELEC5208-配电网与储能/)** | 硕士课程｜OpenDSS、Julia、HEMS 与动态运行区间 |
| 05 | **[光伏 MPPT 与风机运行特性实验](05-ELEC5206-新能源实验/)** | 硕士实验｜测量数据处理、特性曲线与最大功率点 |
| 06 | **[温湿度传感器节点与 PCB 设计](06-施耐德实习-PCB设计/)** | 实习项目｜KiCad 原理图、PCB、制造与装配资料 |
| 07 | **[考虑用户偏好与配网约束的 P2P 能源交易](07-硕士研究-P2P能源交易/)** | 硕士研究进行中｜交易机制与配电网约束 |
